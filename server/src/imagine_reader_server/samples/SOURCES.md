# Sample books

The samples are shared by every visitor and are in the public domain.

- `the-lantern-keeper.pdf`: *The Lantern Keeper*, written for this project and
  dedicated to the public domain (CC0); generated by `fixtures/generate_pdfs.py`.
- `the-lantern-keeper-cover.webp`: its cover, shown in the libraries and the
  reader instead of its first page. The picture was drawn for this project by
  FLUX.2 [klein] 4B (Black Forest Labs, on Cloudflare Workers AI) from a
  description of the story; the title is set in Literata (SIL Open Font
  License 1.1) and Atkinson Hyperlegible (SIL Open Font License 1.1). It is
  dedicated to the public domain (CC0), like the story.
- `devdas.pdf`: the first two chapters of *দেবদাস* by Sarat Chandra
  Chattopadhyay (1876–1938), first published 1917. The text is from Bangla
  Wikisource (bn.wikisource.org), proofread from a public-domain scan; the
  first page is that scan's title page (Sarkar & Co., Kolkata, 1355/1949).
  The pages are set in Noto Serif Bengali (SIL Open Font License 1.1). How it
  was made: `tools/samples/bangla/README.md`.
- `kabuliwala.pdf`: the whole of *কাবুলিওয়ালা* by Rabindranath Tagore
  (1861–1941), first published in *Sadhana* in 1892. The text is from Bangla
  Wikisource, proofread from a public-domain scan of *গল্পগুচ্ছ* (প্রথম খণ্ড,
  Visva-Bharati, reprinted 1357/1950–51), with 21 slips corrected against
  that scan. The pages are set in Noto Serif Bengali (SIL Open Font License
  1.1). How it was made: `tools/samples/bangla/README.md`.
